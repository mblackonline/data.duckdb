AI privacy details

Your question, selected table schemas (table and column names and types), sample values from public datasets, and other available table names are sent to Groq (AI provider). If SQL fails, a retry also sends the DuckDB error, which may include SQL or data values. These requests pass through this site's protected backend. Generated SQL runs in your browser using DuckDB.

The operator's Groq key stays on the server. Groq usage is attributed to the operator's account. Microsoft access tokens are sent only to this site's backend, not to Groq. This application does not record keys or questions in application logs. Groq handles requests under its data policies and the operator's retention settings.
